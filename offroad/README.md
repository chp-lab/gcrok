# 🚙 Off Road — ศูนย์บัญชาการฉุกเฉินแบบออฟไลน์ 100%

ระบบบริหารเสบียง/พลังงาน/อุปกรณ์สื่อสาร/คลังความรู้/บันทึกเหตุการณ์ สำหรับช่วงน้ำท่วมและต้องอยู่กับที่ (Shelter-in-Place)
ทำงานบน Windows 10/11 (และ Linux/macOS) ด้วย **Python 3.11+ เท่านั้น — ไม่ต้องติดตั้งแพ็กเกจเพิ่ม ไม่ต้องใช้อินเทอร์เน็ต**

## เริ่มใช้งาน
```
python run.py                 # เปิดเบราว์เซอร์ที่ http://127.0.0.1:8765/
python run.py --local-only    # ไม่เปิดให้อุปกรณ์อื่นเข้าถึง
python run.py --window        # หน้าต่างแอป (ต้อง pip install pywebview — ไม่บังคับ)
```
- อุปกรณ์อื่นใน Wi-Fi/Hotspot เดียวกัน: เปิด URL ที่แสดงในคอนโซล (อ่านได้ทันที, แก้ไขต้องใส่ PIN ที่แสดงตอนเปิดโปรแกรม)
- ข้อมูลทั้งหมดอยู่ใน `data/offroad.db` — สำรองโฟลเดอร์ `data/` และ `knowledge/`
- ค่าตั้งต้นทั้งหมด (ปริมาณเสบียง, โหลดไฟ, ตารางซิม) เป็น **ข้อมูลตัวอย่าง** ให้แก้ให้ตรงกับบ้านจริง
- เอกสารตัวอย่างใน `knowledge/` เป็นเทมเพลต: รายการยา/ขนาดยาให้ปรึกษาแพทย์หรือเภสัชกร

## เวอร์ชันไฟล์เดียว (ไม่ต้องมี Python)
ดาวน์โหลด **`OffRoad.html`** แล้วดับเบิลคลิกเปิดด้วย Chrome/Edge/Firefox — ใช้งานได้ทันทีแบบออฟไลน์
- ข้อมูลเก็บในเบราว์เซอร์ (localStorage) ใช้ปุ่ม **สำรองข้อมูล / นำเข้าข้อมูล** ที่เมนูซ้ายเป็นประจำ (การล้างข้อมูลเบราว์เซอร์จะลบข้อมูล)
- คลังความรู้: สร้าง/แก้ไข/นำเข้าไฟล์ `.md .txt .html` ได้ในหน้า (ไม่รองรับ PDF)
- ไม่มีโหมด LAN — แต่ละอุปกรณ์เก็บข้อมูลแยกกัน; ถ้าต้องการให้ทุกเครื่องเห็นข้อมูลเดียวกัน ใช้เวอร์ชัน `python run.py`
- สร้างไฟล์ใหม่หลังแก้ `web/` หรือ `knowledge/`: `python scripts/build_single_html.py`
